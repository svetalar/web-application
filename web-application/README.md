# FLUPPY — чат-приложение (запуск через Docker)

Веб-приложение на **Java** с базой данных **PostgreSQL**.

---

## Предварительные требования

- Установленный **Docker** и **Docker Compose** (плагин `docker compose`).
---

## Запуск

Из каталога, где лежит `docker-compose.yaml`:

```bash
docker compose up --build
```

Первый запуск займёт несколько минут (скачивание образов и сборка через Maven).
Когда в логах появится строка вида:

```
🎉 Сервер запущен!
📍 Локальный: http://localhost:8080
```

приложение готово.

Откройте в браузере: **http://localhost:8080**

### Запуск в фоне

```bash
docker compose up --build -d   # старт в фоне
docker compose logs -f         # смотреть логи
docker compose down            # остановить
```

---

## Учётные данные по умолчанию

После первого старта создаётся администратор:

| Поле   | Значение |
|--------|----------|
| Логин  | `admin`  |
| Пароль | `admin`  |

> Пароль в `init.sql` записан в открытом виде специально: при старте приложение
> запускает `PasswordMigration`, которая автоматически перехеширует его в bcrypt.
> Поэтому войти под `admin` / `admin` можно сразу после первого запуска.

Обычных пользователей можно создать через форму регистрации на главной странице.

Админ-панель доступна по адресу **http://localhost:8080/admin** (только для роли `ADMIN`).


## Данные и их сброс

- Данные БД хранятся в Docker-томе `pgdata`, загруженные файлы — в томе `uploads`.
- `init.sql` выполняется **только при первой инициализации** пустого тома БД.

Чтобы полностью пересоздать базу с нуля (удалив все данные):

```bash
sudo docker compose down -v   # -v удаляет тома
sudo docker compose up --build
```
